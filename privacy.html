Privacy policy

yt-upload is a private tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels.

Data we access

With the owner's consent the tool uses the YouTube Data API to upload videos, set titles, descriptions and publish times, and read the status of those uploads.

How data is used and stored

Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No data from Google users other than the owner is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
